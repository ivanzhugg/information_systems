ЛР1. Краткие ответы на теоретические вопросы (Python)

1. Что такое класс и объект? Как создать объект?
Класс описывает данные и поведение, объект — конкретный экземпляр класса. Например: supplier = Supplier(1, "Автодеталь", "Москва", "+74951234567"). Переменная supplier хранит ссылку на объект.

2. Что такое инкапсуляция? Как обращаться к полям извне?
Инкапсуляция объединяет данные и методы и позволяет управлять доступом к состоянию. В нашей работе поля имеют имена с __, а доступ выполняется через свойства: supplier.name и supplier.name = "Автоснаб". @property задаёт чтение, @name.setter — изменение с проверкой. _name означает внутренний атрибут по соглашению; __name преобразуется в _ИмяКласса__name. Абсолютной защиты от внешнего доступа в Python нет.

3. Что такое конструктор и зачем он нужен?
Он нужен для создания объекта с начальным состоянием. В Python __new__ создаёт экземпляр, а __init__ инициализирует его поля. Пример объявления: def __init__(self, name): self.__name = name. self — текущий объект; __init__ возвращает None. В нашей реализации он также обеспечивает проверку данных.

4. Как создаётся объект?
При вызове Supplier(...) стандартный механизм вызывает __new__, затем __init__, если получен экземпляр соответствующего класса. __init__ проверяет аргументы и задаёт поля. После успешного завершения ссылка присваивается переменной. Если проверка вызывает исключение, выражение создания не возвращает объект вызывающему коду.

5. Чем статический метод отличается от метода объекта?
Метод объекта получает self и работает с конкретным экземпляром. @staticmethod не получает автоматически ни self, ни cls; его можно вызвать без создания объекта. Примеры: Supplier.validate_phone(value) проверяет телефон до создания поставщика; SupplierShort.from_supplier(supplier) создаёт краткое представление полного объекта. В Python @classmethod — отдельный механизм: он получает класс cls. Наши from_string и from_json используют его как альтернативные конструкторы; несколько определений __init__ не создают перегрузки.

6. Как устроены классы Python и наша иерархия?
Класс может содержать атрибуты, методы и свойства. Поля экземпляра обычно задаются через self в __init__, атрибуты самого класса — в его теле. Классы прямо или косвенно наследуются от object. Наша иерархия: object -> SupplierShort -> Supplier. SupplierShort хранит ID, название и телефон; Supplier добавляет адрес. Python также поддерживает множественное наследование, порядок поиска методов определяется MRO.

7. Что такое наследование и переопределение? Как вызвать метод родителя?
Наследование позволяет использовать поля и методы базового класса. Запись class Supplier(SupplierShort) задаёт наследника. Переопределение — своя реализация унаследованного метода, например __str__ в Supplier. print(supplier) использует эту реализацию. super().__str__() внутри метода наследника обращается к следующей реализации по MRO; в нашей иерархии это SupplierShort.__str__.

8. Как работают конструкторы при наследовании?
Если наследник не объявляет __init__, используется унаследованный метод. Если объявляет, инициализатор родителя автоматически не вызывается: нужен super().__init__(...). В Supplier сначала проверяется адрес, затем super().__init__(supplier_id, name, phone) проверяет и задаёт общие поля, после чего сохраняется адрес. Всё происходит в одном объекте.

9. Какие базовые методы получает объект?
От object наследуются, в частности: __new__ — создание экземпляра; __init__ — инициализация; __str__ — строка для print; __repr__ — представление для отладки; __eq__ — сравнение через ==; __getattribute__, __setattr__, __delattr__ — доступ, присваивание и удаление атрибутов. Их можно переопределять. Наш __eq__ сравнивает тип и ID, а для другого типа возвращает NotImplemented. Оператор is проверяет идентичность объектов. После определения __eq__ без __hash__ наши классы становятся нехешируемыми: их нельзя использовать как ключи dict или элементы set.
